# data-structures-algorithms-python
## Overview

This project implements two Python applications using core data structures 
and object-oriented programming: a priority-based task scheduler and a 
graph-based social media connections manager.

---

## Question 1 — Task Scheduler (Priority Queue)

Built a task scheduling system that organises and retrieves tasks in order 
of priority using an appropriate data structure.

- Task class storing description, due date, priority level, and 
  estimated completion time
- Scheduler class supporting: adding tasks, retrieving the next 
  priority task, printing the task list, and saving/reading tasks to file
- User-friendly main menu for navigating the application

**Key concepts:** Priority queues, OOP, file I/O, Python data structures

---

## Question 2 — Social Media Connections Manager (Graph Theory)

Simulated social network analysis by implementing graph theory to model 
users and their connections.

- Connections manager class supporting: adding users, adding connections, 
  viewing all users and connections, and displaying a visual network graph
- Implemented using OOP principles
- Main menu for navigating the application

**Key concepts:** Graph theory, adjacency structures, OOP, 
network visualisation
